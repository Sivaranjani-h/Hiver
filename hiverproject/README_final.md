# SpotifyCares AI Support Agent

An AI support agent for SpotifyCares that classifies customer intent, drafts a reply
grounded in real historical resolutions, and decides whether to auto-handle or escalate
to a human — built for the Hiver SDE Intern take-home assignment.

**Headline results:** 77.51% intent classification accuracy (vs. 33.73% trivial / 47.93%
simple baseline) · 50.9% of test messages auto-handled by the escalation policy · full failure
analysis and evaluation harness with LLM-judge/human agreement included.

See `report.md` for the full write-up and `decision_log.md` for key design decisions.

## Reproducing the Headline Results (~15 minutes, depending on Groq API latency)

Run in this order. Approximate times are from actual runs during development — Groq API
latency may vary.

```bash
# 1. Build the retrieval index (one-time, ~1 min)
python build_embeddings.py

# 2. Classify all 169 test messages (~8-9 min, calls Groq)
python classify_with_groq.py
#   -> prints overall accuracy + per-intent breakdown
#   -> saves classifier_predictions.csv

# 3. Decide auto-handle vs escalate for all 169 messages (~1 min, local only, no API)
python escalation_decisions.py
#   -> prints the auto-handle/escalate split and reasons
#   -> saves escalation_decisions.csv

# 4. Draft replies for auto-handled messages only (~4-5 min, calls Groq)
python draft_auto_handled.py
#   -> saves final_pipeline_output.csv (the complete system output)
```

**Note on quota:** Groq's free tier has a daily token limit. All scripts above are
resume-safe — if you hit a rate limit, they save progress and can be re-run; already-
completed rows are automatically skipped.

**Data leakage note:** During evaluation, 34 of the original 169 test messages were found
verbatim in the initial retrieval knowledge base. These overlaps were removed before the
final evaluation to prevent misleadingly perfect retrieval scores.

**If you're re-running from scratch** (not using the provided `test_set.csv` and
`knowledge_base_sample.csv`), see `report.md` Section 2 for how the original dataset
(Kaggle `thoughtvector/customer-support-on-twitter`) was filtered down to SpotifyCares
and split into these files — this one-time extraction is not included in the 15-minute
reproduction window, per the assignment's guidance that full-dataset processing isn't
expected.

## Known Limitations

See `report.md` Sections 5 and 6 for the full failure analysis and an honest discussion
of what the headline numbers do and don't capture. In short: the system reliably matches
topic and tone but has no dependable way to distinguish safe generic language from
confident-sounding fabrication — this is the single most important open problem.
